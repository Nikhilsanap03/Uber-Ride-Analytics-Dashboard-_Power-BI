## 📊 Project Overview
This project focuses on analyzing Uber ride data using **Power BI** to generate meaningful business insights. The dashboard provides a comprehensive view of ride performance, revenue trends, customer behavior, and vehicle-wise analysis to support data-driven decision-making.

## 🎯 Objectives
- Analyze completed, cancelled, and incomplete rides  
- Track revenue, total distance, and average ride distance  
- Understand customer behavior and ride patterns  
- Compare performance across different vehicle types  

## 🔍 Key Insights
- Analyzed **93K+ completed bookings** and **₹51.85M total revenue**
- Identified revenue and demand trends by **month and quarter**
- Performed **vehicle-wise analysis** (Auto, Bike, Go Mini, Sedan, Uber XL)
- Evaluated **ride completion and cancellation reasons**
- Analyzed **top pickup and drop locations**

## 🛠 Tools & Technologies
- Power BI  
- DAX  
- Power Query  
- Data Modeling  
- Data Visualization  

## 📈 Dashboard Features
- Interactive KPIs for bookings, revenue, distance, and customer count  
- Time-based analysis (Monthly & Quarterly)  
- Vehicle-type and customer segmentation  
- Filters, slicers, and drill-down capabilities  

## 📁 Dataset
- Uber ride booking data (sample / anonymized dataset used for analysis)

## 🚀 Outcome
The dashboard helps identify operational trends, improve ride completion rates, optimize revenue, and enhance customer experience through actionable insights.
